# v0.93.0-rc.2 部门负责人模板可见性热修

## Outcome

- 根因：前端把页面级模板管理能力直接映射为 `scope=manage`，导致全局 ACTIVE 和跨部门共享模板虽可读、可实例化，却从部门负责人列表中消失。
- 测试先行：先增加“共享模板可见、可实例化、不可管理”场景；旧实现出现 3 项预期失败，修复后定向 4/4 通过。
- 修复：并行加载可读 ACTIVE 与可管理模板，按 ID 去重；设计、复制、改名、可用部门、归档、删除及运行统计按逐模板管理集合控制。
- 后端对象级授权没有放宽；部门负责人仍不能修改全局模板或完整 scope 超出其管理范围的共享模板。
